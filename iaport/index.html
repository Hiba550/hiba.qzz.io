02 / Alpha notes

Current alpha status.

This is a working-port guide, not the release page. The current project notes preserve source flight simulation, collision, equipment, aircraft HUD, inventory/storage and the two-step dismount system while seating is still being checked against real Bedrock client behaviour.

The 0.2.58 seating pass deliberately keeps the visible Bedrock player upright on Biplane and Bamboo Hopper instead of copying Java’s rider rotation when that caused the player to detach from the cockpit.

Gameplay video, install instructions and the public .mcaddon will be added here after the next client pass.
